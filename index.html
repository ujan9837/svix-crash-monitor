How this page is made

  1. Every morning at 14:30 UTC, once CME's settlement prices from the evening before have reached Databento, a GitHub Actions workflow pulls the latest session of E-mini S&P 500 option settlements, with a Databento API key stored as a repository secret.
  2. It computes SVIX and the three probabilities for that session and adds the row to the history: one CSV, kept on the repository's monitor-history branch, one small commit a day. The main branch holds only code.
  3. It rebuilds this page from the history and publishes it on the gh-pages branch, which GitHub Pages serves.

Sources: end-of-month E-mini S&P 500 options (CME Globex, root EW), daily settlement prices, from Databento; this page shows only quantities computed from them, never the prices. The Cboe VIX (VIXCLS) and the one-month Treasury yield (DGS1MO), from FRED, Federal Reserve Bank of St. Louis.

Methods: Ian Martin (2017), “What is the Expected Return on the Market?” Quarterly Journal of Economics 132(1); Ian Martin and Ran Shi (2025), “Forecasting Crashes with a Smile.” The engine that recovers the risk-neutral distribution is the work of Riley Haas and Marija Jovicic.
